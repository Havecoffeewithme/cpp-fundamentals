# C++ Fundamentals Practice

This repository contains a collection of beginner-friendly C++ programs created to practice the core concepts of the C++ programming language.

## Topics Covered

* User input and output using `cin`, `cout`, and `getline()`
* Variables and basic data types
* Type casting
* Arithmetic operations
* Typedef aliases
* String manipulation
* Console-based interaction

## Programs Included

### 1. User Information Program
Prompts the user to enter their name, age, and address, then displays the information in a friendly format.

### 2. Type Casting Example
Demonstrates:
* Converting a floating-point number to an integer
* Calculating a percentage using explicit type casting

### 3. Typedef Example
Shows how `typedef` can be used to create aliases for existing data types, making code easier to read and maintain.

## Technologies Used

* C++
* Standard Template Library (STL)
* Console Application

## Learning Objectives

This project was created to strengthen understanding of:
* Variables and data types
* User input and output
* Type casting
* Typedef aliases
* Basic C++ syntax and programming fundamentals
